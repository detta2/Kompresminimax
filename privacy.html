Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 1 Januari 2026

1. Komitmen Privasi 100% Client-Side

Di KompresMiniMax, privasi dan integritas data pengguna adalah fondasi utama kami. Semua berkas yang Anda pilih (PDF, JPG, PNG, WEBP) diproses 100% secara lokal di peramban (browser) menggunakan JavaScript dan WebAssembly (PDF-Lib). File Anda TIDAK PERNAH dikirim, diunggah, maupun disimpan di server manapun.

2. Data yang Kami Kumpulkan

Karena kami tidak menggunakan server pengolahan file, kami tidak mengoleksi dokumen identitas, pas foto, sertifikat, atau dokumen PDF sensitif Anda. Informasi yang mungkin dicatat mencakup:

  • Data analitik standar (jenis browser, resolusi layar, negara, durasi kunjungan) untuk peningkatan performa.
  • Pilihan preferensi bahasa (ID/EN) yang disimpan di penyimpanan lokal browser (LocalStorage).

3. Penggunaan Cookie & Google AdSense

Situs ini dapat menggunakan cookie pihak ketiga, termasuk Google, untuk menayangkan iklan relevan berdasarkan kunjungan pengguna sebelumnya ke situs ini atau situs web lain. Kebijakan periklanan Google diatur oleh Kebijakan Privasi & Ketentuan Google. Pengguna dapat memilih untuk menonaktifkan iklan hasil personalisasi dengan mengunjungi Setelan Iklan Google.

4. Keamanan Informasi

Karena tidak ada transmisi berkas melalui jaringan internet, risiko intersepsi data atau peretasan server berkas tereliminasi sepenuhnya. Dokumen Anda tetap berada di perangkat pribadi Anda setiap saat.
